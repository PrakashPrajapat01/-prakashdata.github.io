# Prakash — Portfolio Website

## Edit your portfolio
- Update `index.html` to change text, sections, links and project descriptions.
- Replace `assets/profile.jpg` with your own profile photo (keep the same filename).
- Add certificate images to `certificates/` and add their cards in the Certifications section.
- Add project screenshots to `assets/` and edit the Projects section.
- Public GitHub repositories are fetched automatically from the GitHub API (up to 100 repositories per request).

## Publish with GitHub Pages
1. Create a repository named `PrakashPrajapat01.github.io` under your GitHub account.
2. Upload all files and folders from this package to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch → `main` → `/ (root)` → Save.
5. Wait for GitHub Pages to publish the site.

## Contact form
EmailJS is configured with the credentials supplied for this portfolio. In the EmailJS template, make sure the template variables match `from_name`, `from_email`, `subject`, `message`, and `to_email`. Keep the public key client-side only; never put a private EmailJS access token in this repository.
